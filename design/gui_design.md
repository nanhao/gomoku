# GUI 包详细设计文档

## 1. 概述

### 1.1 设计目标
- 提供五子棋游戏的图形用户界面
- 支持三种游戏模式：人人对战、人机对战、AI 内战
- 支持 AI 对战回放功能
- 采用森林/小动物主题的可爱风格 UI

### 1.2 技术栈
- Python 3.x
- Tkinter（标准 GUI 库）
- 项目内依赖：game 包、ai 包

### 1.3 目录结构
```
gui/
├── __init__.py              # 包初始化，导出主要组件
├── main.py                  # 主程序入口，包含 GomokuGUI 类
└── components/              # 组件子包
    ├── __init__.py          # 组件导出
    ├── constants.py         # 常量定义（颜色、尺寸、字体）
    ├── mode_selector.py     # 游戏模式选择器
    ├── game_board.py        # 棋盘组件
    ├── ai_battle.py         # AI 内战相关组件
    ├── replay_browser.py    # 回放浏览器
    ├── replay_viewer.py     # 回放查看器
    └── heatmap.py           # 热力图组件
```

## 3. 组件设计

### 3.1 游戏模式选择器 (mode_selector.py)

#### GameModeSelector 类
**职责**：游戏启动时显示模式选择界面

**窗口属性**：
- 尺寸：400x600 像素
- 标题："🐻 森林五子棋 - 选择游戏模式 🐰"
- 不可调整大小
- 屏幕居中显示

**界面布局**：
```
+------------------+
|    🐻 森林五子棋 🐰   |  <- 标题（36px emoji + 24px 文字）
|    请选择游戏模式      |  <- 副标题
+------------------+
| [👥 人人对战]       |  <- 绿色按钮 #90EE90
| 两位玩家轮流对弈      |
+------------------+
| [🤖 人机对战]       |  <- 蓝色按钮 #87CEEB
| 玩家 vs AI 电脑     |
+------------------+
| [⚔️ AI 内战]        |  <- 紫色按钮 #DDA0DD
| AI 自动对战模式      |
+------------------+
| ---- 分隔线 ----   |
+------------------+
| [📺 查看回放]       |  <- 黄色按钮 #F0E68C
| 查看历史 AI 对战记录  |
+------------------+
```

**交互逻辑**：
1. 点击"人人对战" → 关闭窗口，返回 `{"mode": "pvp"}`
2. 点击"人机对战" → 弹出配置对话框
   - 选择 AI 对手（下拉框：random / fc_v1）
   - 选择"执黑棋" → 返回 `{"mode": "pve", "player_color": "black", "ai": "..."}`
   - 选择"执白棋" → 返回 `{"mode": "pve", "player_color": "white", "ai": "..."}`
3. 点击"AI 内战" → 弹出配置对话框
   - 选择双方 AI（下拉框）
   - 输入对战局数（1-100）
   - 点击"开始对战" → 返回 `{"mode": "ai_vs_ai", "num_games": n, "ai1": "...", "ai2": "..."}`
4. 点击"查看回放" → 返回 `{"mode": "replay"}`

**按钮样式**：
- 字体：微软雅黑 14px bold
- 背景色：根据类型不同（绿/蓝/紫/黄）
- 悬停效果：变为小熊棕(#D2691E)，文字变白
- 边框：RAISED，bd=3

### 3.2 棋盘组件 (game_board.py)

#### GameBoard 类
**职责**：负责棋盘的绘制和交互

**常量定义**：
```python
BOARD_SIZE = 15          # 15x15 棋盘
CELL_SIZE = 42           # 格子大小 42px
BOARD_MARGIN = 50        # 边距 50px
COLOR_BOARD = "#E3C16F"  # 棋盘背景
COLOR_LINE = "#8B4513"   # 线条颜色
COLOR_BLACK = "#2C2C2C"  # 黑子
COLOR_WHITE = "#FFFAF0"  # 白子
COLOR_LAST_MOVE = "#FF6B35"  # 最后落子标记
```

**画布尺寸计算**：
```
canvas_size = BOARD_MARGIN * 2 + CELL_SIZE * (BOARD_SIZE - 1)
            = 50 * 2 + 42 * 14
            = 688 px
```

**绘制内容**：
1. **网格线**：15条横线 + 15条竖线
2. **星位**：9个星位点（天元及四角）
   - 位置：(3,3), (3,7), (3,11), (7,3), (7,7), (7,11), (11,3), (11,7), (11,11)
   - 大小：半径 3px 的圆点
3. **棋子**：
   - 黑子：#2C2C2C，带阴影效果
   - 白子：#FFFAF0，带阴影效果
   - 半径：16px（主棋子）+ 18px（阴影）
4. **最后落子标记**：橙色圆圈，半径 20px，线宽 3px

**交互**：
- 点击棋盘 → 计算点击位置对应的行列 → 调用 `on_click_callback(row, col)`
- 点击位置计算：考虑 BOARD_MARGIN 偏移

**公共方法**：
```python
def draw_board()                    # 绘制空棋盘
def draw_pieces(board, last_move)   # 绘制棋子（board: 15x15 二维数组）
def pack(**kwargs)                  # 包装布局
def grid(**kwargs)                  # 网格布局
```

### 3.5 回放查看器 (replay_viewer.py)

#### ReplayViewer 类

**界面布局**：
```
+----------------------------------------------------------+
| [⏮上一步] [⏭下一步] [⏩跳转到结局] [🔄重置]  第 X / Y 步 |
```

### 3.6 热力图组件 (heatmap.py)

#### HeatmapCanvas 类
**职责**：绘制 reward 热力图

**常量定义**：
```python
PRIMARY_COLORS = [          # 9种正色
    (0, 0, 0),       # 0: 黑
    (128, 0, 128),   # 1: 紫
    (0, 0, 255),     # 2: 蓝
    (0, 128, 0),     # 3: 绿
    (255, 255, 255), # 4: 白
    (255, 255, 0),   # 5: 黄
    (255, 165, 0),   # 6: 橙
    (255, 192, 203), # 7: 粉
    (255, 0, 0),     # 8: 红
]
GLOBAL_MAX_ABS = 1000000    # 全局最大绝对值（用于归一化）
```

**颜色映射规则**：
- 9种正色之间分5档，共40档颜色梯度
- reward = 0 → 白色
- |reward| 越小 → 越接近白色
- |reward| 越大 → 颜色越深（趋近黑色或红色）
- 归一化：normalized = reward / GLOBAL_MAX_ABS

**画布尺寸**：280x280 像素
- cell_size = 16px
- margin = 20px

#### HeatmapLegend 类
**职责**：显示热力图颜色标尺

**显示内容**：
1. 标题："颜色标尺 (min → max):"
2. 渐变条：40个颜色块（每个 6px 宽）
3. 颜色标签：9个正色名称（黑、紫、蓝、绿、白、黄、橙、粉、红）

```python
def __init__(self, root, game_mode="pvp", ai_player=None, ai_model="random")
```

- `ai_player`: AI 执棋颜色（1=黑，2=白，人机对战模式使用）
- `ai_model`: AI 模型名称（"random", "fc_v1" 等，人机对战模式使用）

### 4.3 AI 引擎创建
```python
def _create_ai_engine(self, ai_name)
```
根据名称创建对应的 AI 引擎：
- "random" → RandomModel
- "fc_v1" → FCv1Model
- 其他 → RandomModel（默认）

### 4.4 主函数流程
```
1. 创建 GameModeSelector → 获取用户选择
2. 根据模式处理：
   - ai_vs_ai: 运行 AIBattleProgressWindow → 可选回放
   - replay: 运行 ReplayBrowser → ReplayWindow
   - pvp: 创建 GomokuGUI(game_mode="pvp")
   - pve: 创建 GomokuGUI(game_mode="pve", ai_player=..., ai_model=...)
```

## 5. 关键交互规范

### 5.1 坐标系统
- 使用 (row, col) 坐标，范围 0-14
- row：行（从上到下）
- col：列（从左到右）
- 与 game 包保持一致

### 5.2 错误处理
- 重复落子：静默处理（不弹窗）
- 游戏未开始时点击棋盘：提示"请先新建游戏"

### 5.3 自动保存
- 游戏开始时自动保存
- 每次落子后自动保存
- 游戏结束时自动保存

### 5.4 人机对战流程
1. 玩家落子
2. 检查游戏结束
3. 若轮到 AI，延迟 500ms 后 AI 落子
4. 更新棋盘显示
