## 2. 游戏设计

### 2.1 游戏规则

#### 2.1.1 棋盘规格
- **棋盘大小**: 15 × 15 网格
- **坐标系统**: 0-based 索引，范围 0 ≤ x < 15, 0 ≤ y < 15
- **坐标表示**: (x, y) 表示第 x 行第 y 列的落子点

#### 2.1.2 棋子表示
- **空位**: 数值 0
- **黑子**: 数值 1
- **白子**: 数值 2
- **显示符号**: 根据显示设计确定（见 4.4 节）

#### 2.1.3 游戏流程
1. **初始状态**: 棋盘为空，黑方先手（当前玩家 = 1）
2. **落子顺序**: 玩家轮流落子，不可跳过
3. **胜利条件**: 任意玩家在横、竖、斜任一方向上形成连续 5 个或以上同色棋子
4. **平局条件**: 棋盘已满且无人获胜
5. **游戏结束**: 达到胜利条件或平局条件

### 2.2 数据结构

#### 2.2.1 棋盘数据结构
```python
board: list[list[int]]  # 15×15 二维数组，元素值：0=空, 1=黑, 2=白
```

#### 2.2.2 落子记录数据结构
```python
move: dict = {
    "x": int,      # 落子行坐标 (0-14)
    "y": int,      # 落子列坐标 (0-14)
    "player": int  # 落子方 (1=黑, 2=白)
}
```

#### 2.2.3 游戏状态数据结构
```python
game_state: dict = {
    "board": list[list[int]],      # 当前棋盘状态
    "current_player": int,         # 当前落子方 (1=黑, 2=白)
    "winner": int,                 # 获胜方 (0=未结束, 1=黑胜, 2=白胜)
    "history": list[dict]          # 历史落子记录列表
}
```

### 4.2 游戏逻辑设计

#### 4.2.1 胜利检测算法

**算法思路**: 以最后落子点为中心，在4个方向上检测连续棋子

**检测方向**:
- 水平方向: 左 ← → 右
- 垂直方向: 上 ↑ ↓ 下
- 主对角线: 左上 ↖ ↘ 右下
- 副对角线: 右上 ↗ ↙ 左下

**算法伪代码**:
```python
def check_winner(board, last_move):
    x, y = last_move.x, last_move.y
    player = board[x][y]
    
    directions = [
        [(0, -1), (0, 1)],      # 水平
        [(-1, 0), (1, 0)],      # 垂直
        [(-1, -1), (1, 1)],     # 主对角线
        [(-1, 1), (1, -1)]      # 副对角线
    ]
    
    for direction in directions:
        count = 1  # 当前落子
        
        # 正向检测
        for dx, dy in [direction[0]]:
            nx, ny = x + dx, y + dy
            while 0 <= nx < 15 and 0 <= ny < 15:
                if board[nx][ny] == player:
                    count += 1
                else:
                    break
                nx += dx
                ny += dy
        
        # 反向检测
        for dx, dy in [direction[1]]:
            nx, ny = x + dx, y + dy
            while 0 <= nx < 15 and 0 <= ny < 15:
                if board[nx][ny] == player:
                    count += 1
                else:
                    break
                nx += dx
                ny += dy
        
        if count >= 5:
            return player
    
    return 0
```

**时间复杂度**: O(1) - 固定检测4个方向，每次最多检测14步

#### 4.2.2 平局检测算法

**检测条件**: 棋盘已满且无获胜方

**算法伪代码**:
```python
def is_draw(board, winner):
    if winner != 0:
        return False
    
    for row in board:
        for cell in row:
            if cell == 0:
                return False
    
    return True
```

**时间复杂度**: O(n²) = O(225) - 需要遍历整个棋盘

#### 4.2.3 落子验证

**验证规则**:
1. 坐标必须在有效范围内: 0 ≤ x < 15, 0 ≤ y < 15
2. 目标位置必须为空: board[x][y] == 0
3. 游戏未结束: winner == 0

**错误处理**:
- 坐标越界 → 返回错误信息
- 位置已被占用 → 返回错误信息
- 游戏已结束 → 返回错误信息

### 5.4 并发处理

#### 5.4.1 存档写入加锁

**实现方案**: 使用文件锁防止并发写入

import fcntl  # Unix/Linux

**简化方案** (推荐):

### 5.5 性能优化

#### 5.5.1 胜利检测优化

**优化点**: 只需检测最后落子点的4个方向

**原因**:
- 只有新落子可能改变游戏状态
- 其他位置在之前的检测中已确认未获胜
- 时间复杂度从 O(n²) 降为 O(1)
