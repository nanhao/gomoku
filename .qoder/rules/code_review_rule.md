检查项：
- 是否有重复代码
- 是否有过长代码
- 系统架构是否合理，模块划分是否满足单一职责原则
- 依赖关系是否合理，是否存在循环依赖
- 接口设计是否满足最小暴露原则
- 是否有安全问题
- 如果涉及并发，是否有并发安全问题
- 代码是否清晰明了
- 代码逻辑是否准确，是否有 bug 或不合理之处
- 是否严格按照了设计文档实现
- 是否考虑了边界条件
- 测试用例是否合理，是否严格体现设计意图，而不是为了实现让步
- 测试用例是否有足够覆盖率
- 其他问题，你应该用批判性思维尽可能的发现更多的问题
