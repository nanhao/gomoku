## 2. 目标与背景

### 2.1 目标

1. **新增步级过滤**：在现有对局级过滤（意图 2）的基础上，进一步按"变异步"过滤——仅保留获胜方引擎实际落子偏离模型首选推荐的那些步，生成训练样本。温度采样始终启用，步级过滤始终生效。
2. **移除 `winning_move` 模式**：该模式仅取每局最后一步，学习信号过于稀疏，`winner_path` 模式已完全覆盖其功能场景。
3. **移除 `--mode` CLI 参数**：由于仅剩 `winner_path` 一种模式，`--mode` 参数无存在必要，直接删除。
4. **移除 `--no-temp-sampling` CLI 参数**：不开启温度采样没有意义，移除该开关。温度采样始终启用。
5. **`--temp-side` 默认值改为 `random`**：让每局随机决定采样方，而非默认双方采样，以更好产生单方采样的变异步数据。
6. **`winner_path` 恢复数据增强**：此前 `winner_path` 因样本量膨胀而强制禁用 D4 增强；现在变异步过滤大幅削减了样本量，故恢复默认开启 D4 增强（8 变换），允许通过 `--no-augment` 关闭。

### 2.2 背景

当前样本生成链路为两阶段：先按对局级规则过滤（仅保留采样方获胜的对局），再按所选模式从对局中抽取步生成样本。现有两种模式——`winning_move`（仅取最后一步）和 `winner_path`（取获胜方每一步）。

**问题**：`winner_path` 模式对获胜方每一步一视同仁，包括采样方"按模型首选正常落子"的步和"通过温度采样偏离首选"的步。前者并不体现温度采样的探索价值——模型已经知道该下哪里了，再用它做训练数据意义有限。真正有学习价值的是"变异步"——温度采样让引擎放弃了模型的首选推荐、走向了次优路径，最终却仍然获胜的步。这些步蕴含了模型未曾重视的棋路信息。

**移除 `winning_move` 的动机**：
- `winning_move` 模式每局仅产出一条样本（最后一步），信号极度稀疏
- `winner_path` 模式（含软标签）已完全覆盖"获胜路径学习"的场景
- 保留两种模式增加维护负担，且两种模式的标签策略不一致

**恢复 `winner_path` 数据增强的动机**：
- 此前 `winner_path` 因每局产出获胜方全部步数、叠加数据增强会导致样本量过大，故关闭了增强
- 变异步过滤大幅减少了每局的样本产出量（仅保留偏离模型首选的步），样本量担忧已不存在
- 默认开启数据增强以充分利用变异步的稀疏信号，同时保留关闭选项供按需使用

## 4. 功能说明

### 4.1 变异步定义

> **变异步**：某一局对弈中采样方的一步，该步引擎实际落子位置**不在**模型输出概率分布的 argmax（所有并列最大概率位置）集合中。

形式化定义：

设棋盘共有 \(N\) 个合法位置（当前为 \(N = 225\)），模型对该步输出的概率分布为向量 \(\mathbf{p} = (p_1, p_2, \dots, p_N)\)，其中 \(p_j\) 表示模型认为位置 \(j\) 为最佳落子的概率。

\[
\text{argmax}(\mathbf{p}) = \{j \mid p_j = \max(\mathbf{p})\}
\]

设该步引擎实际落子对应索引为 \(k\)，则：

- 若 \(k \notin \text{argmax}(\mathbf{p})\) → 该步为**变异步**
- 若 \(k \in \text{argmax}(\mathbf{p})\) → 该步为**非变异步**

**关键语义**：
- 当模型输出存在多个并列最大概率位置时，落在其中任何一个都不算变异步（模型自己也不确定哪个更好）
- 只有引擎（通过温度采样）选择了一个模型明确不优先的位置时，才算变异步
- 此定义仅依赖模型输出的概率分布和实际落子位置，不依赖采样策略等其他信息

### 4.2 完整过滤链路

变异步过滤始终生效。

修改后的样本生成链路：

```
对局级过滤（不变）
    ↓ 单方采样：保留采样方获胜的对局
    ↓ 双方采样：保留全部有胜者的对局
    ↓
步级筛选（始终生效）
    ↓ 对获胜方的每一步：
    ↓   若该步为变异步 → 保留，生成样本
    ↓   若该步非变异步 → 跳过
    ↓
样本生成
    ↓ 对保留的每步：构造软标签（算法不变）
    ↓ 默认执行 D4 增强（8 变换），可通过 --no-augment 关闭
```

**极端情况**：
- 若获胜方全程无变异步（每步温度采样恰好都选中 argmax）：该局产出 0 个样本。此行为是预期内的，无需告警。

## 5. 术语定义

| 术语 | 定义 |
|------|------|
| 变异步（Variant Move） | 引擎实际落子位置不在模型输出 argmax 集合中的一步，反映温度采样带来的探索行为 |
| argmax 集合 | 模型输出 225 维概率分布中，所有概率等于最大值的索引集合 |
| 对局级过滤 | 仅保留采样方获胜对局的过滤规则 |
| 步级过滤 | 本次新增的过滤：在对局级过滤之后，仅保留变异步生成样本 |
| 采样方 | 对局中启用温度采样的一方（black 或 white），另一方走 argmax；双方采样时双方均为采样方 |
| 获胜方步 | 获胜方的每一步。对局级过滤保证单方采样时获胜方=采样方 |
