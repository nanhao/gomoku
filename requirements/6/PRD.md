## 1. 目标与背景

### 1.1 背景

cnn_v3 支持多代模型（gen1, gen2, gen3, gen4...），当前 gen4 是已知的最强基线。项目已有的工具链支持：

- **create_samples.py**：通过自我对弈 + winner_path 模式生成训练样本（获胜方整条路径）
- **train_main.py**：从样本数据训练模型
- **battle.py**：两个 AI 对战并输出胜率统计

但三者需要人工串联执行，无法自动化地持续迭代进化。

### 1.2 目标

新增一个自动化脚本，将「生成样本 → 训练 → 对战评估 → 模型晋升」串联为闭环，自动执行多轮迭代，每次迭代仅在子代模型胜率超过父代时才晋升，否则停止并报告完整统计信息。

核心机制：
- 每轮以当前最强模型（gen4）为父代，通过自我对弈产生训练样本
- 用样本训练子代模型（gen5）
- 父子对战 100 局，子代胜率 > 50% 则晋升（gen5 → gen4），进入下一轮
- 子代胜率 ≤ 50% 则停止，当前 gen4 即为进化终点

### 1.3 不做的事

- 不修改 create_samples.py、train_main.py、battle.py 的任何代码
- 不引入新的训练算法或模型结构
- v1.0 中所有参数硬编码，不做命令行参数化

## 2. 范围与边界

### 2.1 功能范围

| 编号 | 功能 | 说明 |
|------|------|------|
| FR-1 | 模型文件初始化 | 每轮迭代开始时，复制 `gen4/cnn_v3.pth` → `gen5/cnn_v3.pth`（若 gen5 目录不存在则自动创建） |
| FR-2 | 样本生成 | 调用 `create_samples.py`，以 cnn_v3.4 自我对弈，winner_path 模式，收集 500 局样本局后停止，输出到 `ai/merge_samples/v4/path{i}.json` |
| FR-3 | 模型训练 | 调用 `train_main.py`，用当前轮样本训练 cnn_v3.5，1 个 epoch，batch-size 4096，shuffle 开启 |
| FR-4 | 对战评估 | 调用 `battle.py`，cnn_v3.4 vs cnn_v3.5，100 局 |
| FR-5 | 胜率判定 | 从 battle.py 的标准输出中提取 cnn_v3.5 的胜率（含平局分母），与 50% 阈值比较 |
| FR-6 | 模型晋升 | 子代胜率 > 50% 时，将 `gen5/cnn_v3.pth` 移动（覆盖）到 `gen4/cnn_v3.pth`，i 自增，进入下一轮 |
| FR-7 | 单轮日志 | 每轮迭代开始和结束时打印关键信息（轮次、i 值、样本数、训练状态、对战结果、是否晋升） |
| FR-8 | 最终统计 | 停止后打印完整统计报告（见 §4.2） |

### 2.2 边界

- **仅支持 cnn_v3 模型**：脚本硬编码 cnn_v3.4 和 cnn_v3.5，不支持其他模型
- **不修改模型权重目录结构**：gen4/ 目录必须已存在于 `ai/models/cnn_v3/` 下；gen5/ 目录由脚本按需自动创建
- **依赖 gen4 初始权重**：首次运行前 `gen4/cnn_v3.pth` 必须存在
- **输出目录**：样本输出目录 `ai/merge_samples/v4/` 由脚本自动创建（若不存在）
- **子进程失败即停止**：任何子进程（create_samples / train_main / battle）返回非零退出码时，脚本立即停止并报错，不做自动重试

## 3. 功能说明

### 3.1 整体流程

```
i = 1
循环：
  ├─ (1) 打印"第 i 轮开始"
  ├─ (2) cp gen4/cnn_v3.pth → gen5/cnn_v3.pth
  ├─ (3) create_samples.py（cnn_v3.4 自对弈 → path{i}.json）
  ├─ (4) train_main.py（用 path{i}.json 训练 cnn_v3.5）
  ├─ (5) battle.py（cnn_v3.4 vs cnn_v3.5，100 局）
  ├─ (6) 提取 cnn_v3.5 胜率
  ├─ (7) 打印本轮结果
  ├─ (8) 若胜率 > 50%：
  │         mv gen5/cnn_v3.pth → gen4/cnn_v3.pth
  │         i++
  │         回到 (1)
  └─ 否则：
            打印完整统计报告
            停止
```

### 3.2 各步骤详细参数

#### 步骤 (3)：样本生成

```bash
python ai/create_samples.py \
  --model cnn_v3.4 \
  --mode winner_path \
  --sample_games 500 \
  --output ai/merge_samples/v4/path{i}.json \
  --temp-side random
```

| 参数 | 值 | 说明 |
|------|-----|------|
| --model | cnn_v3.4 | 使用当前 gen4 模型进行自对弈 |
| --mode | winner_path | 取获胜方整条路径作为样本 |
| --sample_games | 500 | 收集 500 局样本局后停止 |
| --output | ai/merge_samples/v4/path{i}.json | 输出文件，{i} 替换为当前轮次 |
| --temp-side | random | 每局随机选一方启用温度采样，增强探索多样性 |

> **样本保留策略**：每轮的样本文件以 `path{i}.json` 独立命名，不覆盖前轮样本。这有助于事后分析每轮迭代的训练数据质量。

#### 步骤 (4)：模型训练

```bash
python ai/train_main.py \
  --model cnn_v3.5 \
  --train-from-dir ai/merge_samples/v4/path{i}.json \
  --epochs 1 \
  --batch-size 4096 \
  --shuffle
```

| 参数 | 值 | 说明 |
|------|-----|------|
| --model | cnn_v3.5 | 训练 gen5 模型 |
| --train-from-dir | ai/merge_samples/v4/path{i}.json | 加载当前轮样本 |
| --epochs | 1 | 仅训练 1 个 epoch |
| --batch-size | 4096 | mini-batch 大小 |
| --shuffle | 开启 | 每 epoch 打乱数据 |

#### 步骤 (5)：对战评估

```bash
python ai/battle.py \
  --ai1 cnn_v3.4 \
  --ai2 cnn_v3.5 \
  --games 100
```

battle.py 会输出形如：
```
cnn_v3.4 胜: 42 局 (42.0%)
cnn_v3.5 胜: 48 局 (48.0%)
平局: 10 局 (10.0%)
```

脚本从标准输出中提取 `cnn_v3.5 胜: ... (...%)` 行的百分比数值作为胜率。

### 3.3 单轮日志格式

每轮迭代至少打印以下信息：

**轮次开始时**：
```
========== 第 {i} 轮迭代开始 ==========
```

**每步完成后**：
- 样本生成完成：打印样本文件路径和实际收集到的样本局数
- 训练完成：打印训练状态
- 对战完成：打印 cnn_v3.4 胜场、cnn_v3.5 胜场、平局数、cnn_v3.5 胜率

**轮次结束时**：
```
第 {i} 轮结果: cnn_v3.5 胜率 = {rate}% → {晋升|停止}
```

### 3.4 最终统计报告

停止后输出的统计报告包含：

| 统计项 | 说明 |
|--------|------|
| 总迭代次数 | 成功完成的轮次数（即 i 的终值 - 1） |
| 逐轮明细表 | 每轮的 i、cnn_v3.4 胜场、cnn_v3.5 胜场、平局数、cnn_v3.5 胜率 |
| 停止原因 | "第 {i} 轮 cnn_v3.5 胜率 {rate}% ≤ 50%，停止迭代" |
| 最终优胜模型 | "当前 cnn_v3.4（gen4）为进化后的最强模型" |

示例输出格式：
```
========== 最终统计 ==========
总迭代次数: 4
逐轮明细:
  第1轮: cnn_v3.4 胜 38 | cnn_v3.5 胜 55 | 平局 7  | cnn_v3.5 胜率 55.0% → 晋升
  第2轮: cnn_v3.4 胜 40 | cnn_v3.5 胜 52 | 平局 8  | cnn_v3.5 胜率 52.0% → 晋升
  第3轮: cnn_v3.4 胜 35 | cnn_v3.5 胜 58 | 平局 7  | cnn_v3.5 胜率 58.0% → 晋升
  第4轮: cnn_v3.4 胜 33 | cnn_v3.5 胜 60 | 平局 7  | cnn_v3.5 胜率 60.0% → 晋升
  第5轮: cnn_v3.4 胜 44 | cnn_v3.5 胜 47 | 平局 9  | cnn_v3.5 胜率 47.0% → 停止
停止原因: 第5轮 cnn_v3.5 胜率 47.0% ≤ 50%，停止迭代
最终优胜模型: gen4/cnn_v3.pth（经 4 轮进化）
```

## 5. 术语定义

| 术语 | 定义 |
|------|------|
| gen4 / cnn_v3.4 | 父代模型，每轮迭代的基线，权重存储在 `ai/models/cnn_v3/gen4/cnn_v3.pth` |
| gen5 / cnn_v3.5 | 子代模型，由 gen4 的样本训练得到，权重存储在 `ai/models/cnn_v3/gen5/cnn_v3.pth` |
| 晋升 | 子代胜率 > 50% 时，将子代权重覆盖父代权重，使子代成为下一轮的父代 |
| winner_path 模式 | create_samples.py 的一种模式，取获胜方整条路径的每一步作为训练样本 |
| 样本局 | create_samples.py 中定义的"有效样本对局"，需满足 winner ∈ {1,2} 且通过 game_filter 过滤 |
| 胜率 | battle.py 输出的百分比，计算公式为 `cnn_v3.5胜场 / 总局数 × 100%`，平局计入分母 |
