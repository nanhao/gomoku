# 棋盘
大小：15x15
表示：
- 二维数组。(x,y) 表示第x行第y列的落子点。范围：0<=x<15, 0<=y<15
- 数组元素值：0表示空位，1表示黑子，2表示白子
游戏参与方：黑白两方。用1表示黑方，用2表示白方。
胜利条件：横、竖、斜线任一方向上出现五子连成一条线（五子以上连成一线也算）。
游戏结束条件：一方达到胜利条件或棋盘已满。棋盘满时算平局。
游戏流程：初始棋盘无子。黑方先手，轮流落子。

## AI 模型接口规范

### 输入格式
- 类型：List[int]
- 长度：226
- 结构：前 225 位是拉直的棋盘（15×15，按行优先展开），最后一位是当前落子方（1=黑棋，2=白棋）
- 棋盘编码：0=空位，1=黑子，2=白子

### 输出格式
- 类型：List[int]
- 长度：225
- 结构：225 个位置的 reward 预期，格式为 [reward(x0,y0), reward(x0,y1), ..., reward(x14,y14)]
- reward 范围：-1000000 <= reward <= 1000000，整数

### 模型类接口
模型需要实现 `predict(board_vector: List[int]) -> List[int]` 方法，返回上述格式的 reward 列表。

## AI 引擎
在模型上层，有一个 ai 引擎，引擎负责连接 ui 跟模型。
- 输入：ui 将棋盘状态（226 维向量）传给引擎
- 处理：引擎把输入传给模型，获得模型输出（225 维 reward 列表）
- 落子选择：
  1. 解析 reward 列表，得到每个 (x, y) 位置的 reward 值
  2. 排除已有棋子的位置
  3. 从剩余位置中选择 reward 最高的位置
  4. 如果多个位置 reward 相同（并列最高），则随机选择一个
- 输出：引擎最终落子成功的位置 (x, y)

## 第一版 AI：random
- 名称：random

- 效果：由于所有位置 reward 相同，引擎会随机选择空位落子

在 `ai` 包中添加评价器模块。

**输入**：`ai_data/{轮次目录}/{局数目录}/record.json`

**示例**：
- 输入：`ai_data/random_vs_random_1/1/record.json`
- 输出：`train_data/random_vs_random_1/1/sample.json`

### sample.json 格式
```json
[
    {
        "input": [...],   // 长度为 226。前 225 位是棋盘，最后 1 位是当前落子方
        "output": [...],  // 长度为 225。格式：[reward(x0,y0), reward(x0,y1), ..., reward(x14,y14)]
        "mask": [...]     // 长度为 225，表示 output 中每个落子点的 reward 是否有效（0/1）。但在本版本中，mask 全置为1，也就是默认 output 中所有的 reward 都有效。但未来版本可能有用，所以代码实现中仍然要有 mask
    }, 
    ...
]
```

### 计算逻辑

**常量定义**：
- `max_reward = 1000000`（reward 值域最大值）
- `min_reward = -1000000`（reward 值域最小值）
- `r = 0.9`（衰减系数）

**第一步：初始化 sample_dict**
```
sample_dict = []
for (step in history) {
    mask = [1] * 225
    positions = 棋盘上所有 225 个位置
    
    for (position in positions) {
        if (position 位置已有棋子) {
            position.reward = min_reward
        } else {
            position.reward = 0
        }
    }
    
    sample_dict.append({
        "input": step.input,
        "output": positions 转换为 225 维数组,
        "mask": mask
    })
}
```

**第二步：反向传播计算 reward**

假设一局游戏中黑白双方落子序列：
- 黑方（获胜）：a1 → a2 → a3 → a4（win）
- 白方（失败）：b1 → b2 → b3

计算规则：
- 获胜方最后一步：`reward(a4) = max_reward`
- 获胜方前面每步：`reward(ai) = r * reward(a(i+1))`
- 失败方最后一步：`reward(b3) = min_reward`
- 失败方前面每步：`reward(bi) = r * reward(b(i+1))`

更新 sample_dict：
```
for (action in action_list) {
    action.reward = 按上述规则计算
    sample_dict[action.step_index].output[action.reward_index] = action.reward
}
```

### 触发方式
AI 内战完成后，自动调用评价器生成 sample.json。

- 映射公式：normalized = reward / max_abs → 映射到 40 档颜色

# 第十二次追加
把 fc_v1 和 cnn_v1 的 reward 反向传播算法更新为：

## 新的 reward 反向传播算法
假设一局游戏中黑白双方落子序列：
- 黑方（获胜）：a1 → a2 → a3 → a4 -> ... -> an（win）
- 白方（失败）：b1 → b2 → b3 -> ... -> b(n-1)

其中, a(j1)、a(j2)、a(j3)、a(j4)、a(j5) 这五步的落子构成了一条线，则
- reward(a(j5)) = max_reward
- reward(a(j4)) = r * reward(j5)
- reward(a(j3)) = r * reward(j4)
- reward(a(j2)) = r * reward(j3)

注意，j5=n。j1,j2,j3,j4,j5不一定连续。

# 第十三次追加
再次修改 reward 算法。
新算法称为双向棋型检测法：

对一局对局中的每一步，应用以下计算规则：
for (position in 棋盘上每一个空位) {
    shape_list1 = detect_shapes(board, position, player)
    reward1 = max(shape_list1.each(shape -> shape_to_reward(board, shape1, player, true)))
    
    shape_list2 = detect_shapes(board, position, opponent_player)
    reward2 = max(shape_list2.each(shape -> shape_to_reward(board, shape2, opponent_player, false)))

    position.reward = max(reward1, reward2)
