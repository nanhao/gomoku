## 2. 目标与背景

### 2.1 背景

`ai/create_samples.py` 支持通过 `--temp-side` 参数指定温度采样的启用方（black / white / both / random）。在单方采样模式下，一方使用温度采样进行探索，另一方使用 argmax 贪心策略。当前脚本对所有非平局对局都生成训练样本，不区分获胜方是否为采样方。

然而，只有采样方获胜的对局才具有学习意义——贪婪方获胜说明采样探索未能产生更优解，从这类对局学习可能引入噪声。

### 2.2 目标

为 `create_samples.py` 增加对局级过滤机制：在单方温度采样模式下，仅保留采样方获胜的对局生成训练样本，自动丢弃贪婪方获胜的对局。非单方采样模式下行为不变。

### 2.3 约束

- 本次修改仅影响 `create_samples.py` 的行为，其他脚本行为不变
- 被过滤的对局不产生任何样本；保留的对局内样本生成逻辑不变

## 3. 范围边界

### 3.1 纳入范围

| 功能 | 说明 |
|------|------|
| 单方采样过滤 | `--temp-side black` 或 `--temp-side white` 时，仅采样方获胜的对局生成样本 |
| random 模式过滤 | `--temp-side random` 时，按每局实际采样方动态判定，仅该采样方获胜的对局生成样本 |
| 过滤统计输出 | CLI 输出中展示过滤统计信息 |

### 3.2 排除范围

| 项 | 排除原因 |
|----|---------|
| temp_side=both 时的过滤 | 双方均采样，不存在唯一采样方，过滤前提不成立 |
| --no-temp-sampling 时的过滤 | 无采样方，过滤前提不成立 |
| 其他脚本的过滤行为 | 明确约束：不影响 create_samples.py 以外的脚本 |
| GUI 验收工具的改造 | 与本功能无关 |
| 样本内部过滤（步级过滤） | 过滤粒度为对局级 |

## 4. 功能说明

### 4.1 过滤规则

对每局对弈，按以下判定逻辑决定是否生成样本：

| 条件 | 采样方 | 对局结果 | 是否生成样本 | 说明 |
|------|--------|----------|-------------|------|
| `--temp-side black` | 黑方 | 黑胜 | 是 | 采样方获胜 |
| `--temp-side black` | 黑方 | 白胜 | 否 | 贪婪方获胜 |
| `--temp-side black` | 黑方 | 平局 | 否 | 平局本身不生成样本（现有行为） |
| `--temp-side white` | 白方 | 白胜 | 是 | 采样方获胜 |
| `--temp-side white` | 白方 | 黑胜 | 否 | 贪婪方获胜 |
| `--temp-side white` | 白方 | 平局 | 否 | 平局本身不生成样本（现有行为） |
| `--temp-side random` | 每局随机 | 采样方胜 | 是 | 按当局实际采样方判定 |
| `--temp-side random` | 每局随机 | 贪婪方胜 | 否 | 按当局实际采样方判定 |
| `--temp-side both` | — | 任意 | 全部生成 | 非单方采样，过滤不激活 |
| `--no-temp-sampling` | — | 任意 | 全部生成 | 无采样方，过滤不激活 |

### 4.2 CLI 输出变化

#### 过滤激活时（单方采样模式）

在"对局统计"和"样本生成完成"之间新增过滤统计区块，展示保留/过滤对局数及原因拆分。

#### 过滤未激活时（非单方采样模式）

输出一行提示，表明过滤未激活及原因。

具体输出格式由设计阶段确定。

## 5. 术语定义

| 术语 | 定义 |
|------|------|
| 采样方 | 当前对局中启用温度采样的一方（黑方或白方） |
| 贪婪方 | 当前对局中使用 argmax 策略的一方（采样方的对手） |
| 单方采样模式 | `--temp-side` 为 black、white 或 random 的模式，有且仅有一方使用温度采样 |
| 对局级过滤 | 以整局对弈为过滤单位，被过滤的对局不产生任何样本 |
