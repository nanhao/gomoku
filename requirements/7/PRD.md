## 2. 目标与背景

### 2.1 目标

`train_main.py` 脚本新增一个命令行参数 `--lr`，允许用户指定模型训练的初始学习率。

### 2.2 背景

当前 `BaseTrainer` 的初始学习率硬编码为 `DEFAULT_LR = 0.001`，用户无法在命令行中覆盖。虽然训练器已经支持多种学习率调度策略（`--lr-scheduler`、`--lr-step-size`、`--lr-gamma` 等），但这些参数只控制衰减行为，初始学习率始终固定为 0.001。

在实际训练中，不同模型和数据规模可能需要不同的初始学习率。例如，通过 LR Range Test 确定的合适学习率可能是 0.0005 或 0.01，用户需要一种方式在启动训练时直接指定，而不是修改源码。

### 2.3 适用场景

- 用户通过 LR Range Test 确定了最优初始学习率后，通过命令行直接指定
- 对不同模型（fc_v1、cnn_v3 等）使用各自的初始学习率
- 配合学习率调度器（`--lr-scheduler`）使用时，将初始学习率作为衰减的起点

## 3. 范围边界

### 3.1 包含范围

| 范围 | 说明 |
|------|------|
| `train_main.py` 新增 `--lr` 参数 | 接受一个正浮点数作为初始学习率 |
| 训练器接收并应用初始学习率 | 训练器初始化优化器时使用指定值，替代硬编码的 0.001 |
| 命令行帮助信息更新 | `--help` 输出中显示新参数的说明 |
| 训练信息打印 | 训练开始时打印实际使用的初始学习率 |

### 3.2 不包含范围

| 范围 | 说明 |
|------|------|
| 其他脚本的参数化 | 本次仅覆盖 `train_main.py`，不涉及 `iterative_train.py` 等内部调用训练器的脚本 |
| 学习率调度器行为改变 | `--lr` 仅影响初始值，不改变衰减策略的行为逻辑 |
| 动态学习率策略 | 不涉及 warmup、cosine annealing 等新衰减策略 |

## 4. 功能说明

### 4.1 新增参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--lr` | `float` | 否 | `0.001` | 指定初始学习率，必须为正数 |

### 4.2 参数校验

- `--lr` 必须为正浮点数（> 0）
- 未指定时使用默认值 0.001（保持向后兼容）

### 4.3 与现有参数的交互

- **`--lr-scheduler`**：当同时指定 `--lr` 和 `--lr-scheduler` 时，学习率从 `--lr` 指定的值出发，按照调度策略衰减
- **`--lr-step-size` / `--lr-gamma` / `--lr-patience` / `--lr-factor`**：调度器的衰减参数独立于初始学习率，无交互冲突

### 4.4 命令行示例

```bash
# 基本使用：指定学习率 0.0005
python ai/train_main.py --model cnn_v3.2 --train-from-dir ai/train_data/mydata --lr 0.0005

# 配合学习率调度器：从 0.01 开始，每 500 epoch 衰减为 90%
python ai/train_main.py --model cnn_v3.2 --train-from-dir ai/train_data/mydata --lr 0.01 --lr-scheduler step

# 不指定 --lr：行为与当前一致，默认 0.001
python ai/train_main.py --model fc_v1 --train-from-dir ai/train_data/fc_v1_self_play_1
```
