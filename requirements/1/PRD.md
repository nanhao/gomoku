## 2. 目标与背景

### 2.1 背景

`ai/create_samples.py` 是五子棋AI项目的核心脚本，负责执行AI自对弈并生成训练样本。该脚本支持两种模式（winning_move / winner_path）、多种温度采样策略（temperature / temp_moves / temp_side），以及数据增强开关。参数组合较多，生成的数据（record.json + 样本JSON）缺乏直观的可视化验证手段。

### 2.2 目标

为 create_samples.py 提供一个可运行的Web验收工具，使开发者能够：

1. 通过UI填写参数并执行脚本，观察对弈过程和结果
2. 直观查看每局对弈的基本信息列表
3. 通过三行对齐热力图，对比每一步的原始模型输出、温度处理分布、样本分布的差异

### 2.3 验收工具定位

本工具为**验收/调试工具**，严格遵循项目验收工具零耦合原则：
- 不 import 任何业务模块（ai/ 包下的代码）
- 通过子进程调用 create_samples.py 执行对弈
- 通过读取脚本生成的中间产物（record.json、样本输出文件）进行可视化
- 工具本身不含任何业务逻辑（对弈编排、样本生成、统计计算等）

## 4. 功能说明

### 4.1 参数填写区

**功能描述**：提供一个表单区域，让用户填写 create_samples.py 的全部CLI参数，自动预填充默认值，并提供"执行"按钮触发脚本运行。

**参数列表**：

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| model | 下拉 | — | 模型指定，必填。可选值从注册表动态获取：random / fc_v1 / cnn_v1 / cnn_v2 / cnn_v3.1 / cnn_v3.2 / cnn_v3.3 等 |
| mode | 下拉 | winning_move | 样本模式：winning_move / winner_path |
| games | 数字 | 100 | 对局数 |
| output | 文本 | — | 输出文件路径，必填 |
| no-augment | 开关 | 关 | 禁用数据增强 |
| no-temp-sampling | 开关 | 关 | 禁用温度采样 |
| temperature | 数字 | 1.0 | 温度值T（>0） |
| temp-moves | 数字 | 12 | 前N步启用温度采样 |
| temp-side | 下拉 | both | 启用采样方：black / white / both / random |
| temp-seed | 数字 | 空 | 温度采样随机种子（可选，用于复现） |

**交互规则**：

| 规则编号 | 规则描述 |
|----------|---------|
| R1 | 点击"执行"按钮后，按钮灰化不可重复点击，直到脚本执行完毕 |

### 4.2 脚本输出区

**功能描述**：在参数填写区下方，展示 create_samples.py 脚本执行完成后的完整 stdout 和 stderr 输出，帮助开发者查看脚本运行日志和报错信息。

**交互规则**：

| 规则编号 | 规则描述 |
|----------|---------|
| R2 | 脚本执行完毕后，一次性展示完整 stdout/stderr 输出（v1.0 为同步阻塞执行，不提供实时流式输出） |
| R3 | 脚本输出区为纵向可滚动区域，可滚动查看完整输出 |
| R4 | 脚本执行报错时，stderr 输出在脚本输出区中正常展示，不额外弹窗 |
| R5 | 未执行脚本时，脚本输出区显示"请先执行脚本"提示 |

### 4.3 温度采样信息区

**功能描述**：在参数填写区下方，展示本次运行的温度采样全局配置和每步采样状态的概要信息，帮助开发者快速理解采样行为。

**展示内容**：

| 信息项 | 说明 |
|--------|------|
| 温度值 | 该局使用的温度 T 值 |
| 采样步数阈值 | 前 N 步启用采样，之后 argmax |
| 采样方 | 该局实际启用的采样方（黑方 / 白方 / 双方 / random / 无） |

**交互规则**：

| 规则编号 | 规则描述 |
|----------|---------|
| R6 | 温度信息区位于参数填写区和对局列表区之间 |
| R7 | 未执行脚本时，温度信息区显示"请先执行脚本"提示 |
| R8 | 温度信息区展示本次运行的温度采样全局配置，不随对局切换而变化 |

### 4.4 对局列表区

**功能描述**：脚本执行完毕后，展示本次运行的所有对局列表。每条对局元素包含基本信息，可点击选中某局，选中后下方热力图区展示该局的详细热力图。

**每局基本信息**：

| 信息项 | 说明 |
|--------|------|
| 局号 | 从1开始递增的对局编号 |
| 胜负方 | 黑胜 / 白胜 / 平局 |
| 采样方 | 该局启用温度采样的一方：黑方 / 白方 / 双方 / random / 无（全程argmax） |

**交互规则**：

| 规则编号 | 规则描述 |
|----------|---------|
| R9 | 对局列表为纵向可滚动列表 |
| R10 | 点击某局元素，该局高亮选中，热力图区同步切换为该局内容 |
| R11 | 默认选中第一局；无对局数据时，热力图区显示"无数据"提示 |
| R12 | 平局对局（winner=3）灰化显示，点击后热力图区可展示但标注"平局无样本" |

### 4.5 三行热力图区

**功能描述**：按步数列对齐展示三行热力图，直观对比每一步的三种分布差异。

**三行定义**：

| 行编号 | 行名称 | 数据来源 | 缺失时处理 |
|--------|--------|----------|------------|
| Row 1 | 模型原始输出 | 该步模型的原始输出概率分布 | 每步必有，无缺失 |
| Row 2 | 温度处理分布 | 该步经温度采样处理后的概率分布 | 未启用温度采样的步用占位图（灰色棋盘+居中"argmax"文字） |
| Row 3 | 样本分布 | 该步生成的样本输出分布 | 无样本的步用占位图（灰色棋盘+居中"无样本"文字） |

**占位图规范**：

- 占位图尺寸与正常热力图完全一致（15×15棋盘网格）
- 底色为浅灰色（#D0D0D0）
- 居中显示文字标注：argmax步标注"argmax"，无样本步标注"无样本"
- 占位图与正常热力图在同一列中垂直对齐

**布局规则**：

| 规则编号 | 规则描述 |
|----------|---------|
| R13 | 三行热力图按步数列水平排列，每列顶部标注步数编号（如"Step 1"、"Step 2"...） |
| R14 | 三行在同一列中严格垂直对齐：同一步的Row 1/2/3棋盘中心坐标完全对齐 |
| R15 | 热力图区支持横向滚动（对局步数可能多达100+步），滚动条始终可见 |
| R16 | 每个热力图棋盘尺寸固定（如180px×180px），步数多时不缩小 |
| R17 | 热力图颜色方案：直接复用项目已有热力图颜色方案（白→黄→橙→红顺序渐变） |
| R18 | 热力图在空位（含落子位）上着色，已落子位不着色（棋盘底色可见），保证棋形可读；落子位的热力图颜色正常显示，绿色边框叠加在上方标记位置 |
| R19 | 每个热力图棋盘上绘制黑白棋子（当前步的棋盘状态），**落子位不画棋子**，用绿色边框圈出落子位坐标（沿格子边缘绘制，不遮挡格子内部热力图颜色），保证热力图颜色可见 |

**行标签**：

- Row 1 左侧标注"原始输出"
- Row 2 左侧标注"温度分布"
- Row 3 左侧标注"样本分布"

## 7. 术语定义

| 术语 | 定义 |
|------|------|
| record.json | DataRecorder 生成的对局记录文件，包含 history（每步数据）、winner、end_board |
| sampling_probs | 温度采样步记录的225维采样权重，仅在 strategy="sampling" 时存在 |
| 占位图 | 尺寸与正常热力图一致的灰色棋盘图，用于缺失数据步的位置占位 |
| 零耦合原则 | 验收工具不 import 业务模块，仅通过子进程和文件读取与业务交互 |

## 8. 数据流向

```
用户 → [参数填写区] → 子进程调用 create_samples.py
                         ↓  stdout/stderr
               [脚本输出区] ← 实时输出
                         ↓
               record.json (每局) + 样本输出文件
                         ↓
               [工具读取文件] → 解析 → 渲染
                         ↓
               [对局列表区] ← 对局基本信息
               [热力图区] ← 每步三行数据
```
