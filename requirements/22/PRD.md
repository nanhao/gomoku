## 1. 目标与背景

### 1.1 背景

当前 `iterative_train.py`（意图 13 引入参数化改造后）采用**无条件晋升**策略：每轮训练结束后，无论 ai2（挑战者）对战 ai1（冠军）的胜率如何，始终用 ai2 覆盖 ai1，进入下一轮。

无条件晋升的问题：
- 若 ai2 训练效果不佳（胜率远低于 50%），仍然会覆盖 ai1，导致模型**退化**——下一轮的起点是一个更弱的模型
- 退化后的模型继续生成样本、训练下一代，可能引发**连锁退化**，迭代进化失去意义

### 1.2 目标

将晋升策略从**无条件晋升**改为**条件晋升**：

- 仅当 ai2 对战 ai1 的胜率 **> 55%** 时，ai2 晋升为新一代 ai1
- 若胜率不足，**丢弃本次训练结果**，用原 ai1 重新启动下一轮
- 同时将 `sample_games` 和 `epochs` 两个关键参数从硬编码常量提升为 CLI 可覆盖参数

## 3. 术语定义

| 术语 | 定义 |
|------|------|
| ai1（冠军） | 当前代最强模型，每轮用于生成训练样本和作为对战基准 |
| ai2（挑战者） | 每轮从 ai1 拷贝权重新训练得到的模型，与 ai1 对战后决定是否晋升 |
| 晋升（promote） | 将 ai2 的权重文件覆盖 ai1 的权重文件（`mv ai2 → ai1`），使其成为新的冠军 |
| 胜率 | ai2 在对战中获胜的局数占总对战局数的百分比 |
| 晋升阈值 | 55%，ai2 胜率必须严格大于此值才触发晋升 |
| 样本局数（sample_games） | 每轮 `create_samples.py` 的目标样本局数 |
| 轮次（round） | 一次完整的"生成样本 → 训练 → 对战 → 判定晋升"循环，用 `i` 编号 |

## 4. 功能说明

### 4.1 CLI 参数变更

在现有 `--ai1`、`--ai2`、`--sample_dir` 基础上，新增两个**可选**参数：

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--ai1` | `str` | 是 | 无 | 父代模型 spec，如 `cnn_v4.99`（不变） |
| `--ai2` | `str` | 是 | 无 | 子代模型 spec，如 `cnn_v4.100`（不变） |
| `--sample_dir` | `str` | 是 | 无 | 样本输出目录基路径，如 `ai/merge_samples2`（不变） |
| `--sample-games` | `int` | 否 | `500` | 每轮目标样本局数 |
| `--epochs` | `int` | 否 | `300` | 每轮训练 epoch 数 |

调用示例：
```
python ai/iterative_train.py --ai1 cnn_v4.99 --ai2 cnn_v4.100 --sample_dir ai/merge_samples2 --sample-games 300 --epochs 200
```

### 4.2 迭代训练主流程

每轮迭代按以下步骤执行：

```
1. i = 1（轮次计数器初始化）
2. cp {pth_of_ai1} → {pth_of_ai2}（冠军权重复制给挑战者）
3. 调用 create_samples.py 生成样本：
   --model {ai1} --sample_games {N} --output {sample_dir}\v{gen_of_ai2}\path.json --temp-moves 100
4. 调用 train_main.py 训练 ai2：
   --model {ai2} --train-from-dir {sample_dir}\v{gen_of_ai2} --epochs {M} --batch-size 4096 --shuffle
5. 调用 battle.py 对战评估：
   --ai1 {ai1} --ai2 {ai2} --games 100 --temp-moves=2 --temperature 2 --temp-side both
6. 解析对战输出，得到 ai2 胜率
7. i++：
   - 若 ai2 胜率 > 55% → mv {pth_of_ai2} → {pth_of_ai1}（晋升），回到步骤 2
   - 否则 → 不晋升，直接回到步骤 2
```

### 4.3 条件晋升规则

| 条件 | 行为 |
|------|------|
| ai2 胜率 > 55% | **晋升**：`mv pth_of_ai2 → pth_of_ai1`，下一轮冠军是晋升后的模型 |
| ai2 胜率 ≤ 55% | **不晋升**：ai2 被丢弃，下一轮冠军仍为当前 ai1，重新复制权重、生成样本、训练 |

**注意**：55% 是严格大于，等于 55% 不触发晋升。

### 4.4 日志输出要求

#### 4.4.1 轮次开始

```
========== 第 {i} 轮迭代开始 ==========
```

#### 4.4.2 对战结果（步骤 5 之后）

打印对战统计，包含双方胜场、平局、ai2 胜率、轮次号：

```
{ai1} 胜 {ai1_wins} | {ai2} 胜 {ai2_wins} | 平局 {draws} | 胜率 {win_rate}% | i={i}
```

#### 4.4.3 晋升决策（步骤 7 之后）

**晋升时**：
```
第 {i} 轮结果: {ai2} 胜率 = {win_rate}% > 55% → 晋升
```

**未晋升时**：
```
第 {i} 轮结果: {ai2} 胜率 = {win_rate}% ≤ 55% → 未晋升，重新开始
```

#### 4.4.4 子进程完成

```
样本生成完成: {sample_path}（样本局数: {count}）
训练完成
```

#### 4.4.5 最终统计（Ctrl+C 中断时）

输出格式与现有行为一致，但在逐轮明细中需体现晋升/未晋升状态：

```
========== 最终统计 ==========
总迭代次数: {total}
逐轮明细:
  第1轮: ai1 胜 45 | ai2 胜 42 | 平局 13 | ai2 胜率 42.0%  [未晋升]
  第2轮: ai1 胜 30 | ai2 胜 58 | 平局 12 | ai2 胜率 58.0%  [晋升]
  ...
停止原因: 第{n}轮 ai2 胜率 {r}%，用户中断
当前模型: gen{gen_of_ai1}/{model_name}.pth（经 {total} 轮进化，其中晋升 {promoted_count} 次）
```

| AC-3 | `--epochs` 默认值 | 未传入时为 300 |
| AC-4 | `--epochs` 指定值 | 传入 `--epochs 200` 时，调用 `train_main.py` 携带 `--epochs 200` |

### 5.2 条件晋升

| 编号 | 验收项 | 预期结果 |
|------|--------|---------|
| AC-5 | ai2 胜率 > 55% | 执行晋升（ai2 覆盖 ai1），下一轮冠军为晋升后的模型 |
| AC-6 | ai2 胜率 = 55% | **不晋升**，ai1 保持不变，下一轮从头再来 |

### 5.4 退化保护

| 编号 | 验收项 | 预期结果 |
|------|--------|---------|
| AC-14 | 不被更弱模型覆盖 | 若 ai2 胜率 ≤ 55%，ai1 权重文件保持不变 |
