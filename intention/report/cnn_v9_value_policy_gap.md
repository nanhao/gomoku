# cnn_v9.1 vs cnn_v9.2 模型质量对比调研报告

**日期**: 2026-07-27
**样本源**: `samples/9/v1/sample.json`（MCTS 自对弈产生）

---

## 调研目的

之前发现 cnn_v9.2 对战表现不如预期——value 预测很高但实际落子质量差。本次通过"差一步赢"的临界局面，定量分析两个模型的 policy / value 质量。

---

## 调研过程

### 1. 筛选临界样本

从 11549 个 MCTS 样本中，筛选出**当前方差一步即可获胜**的局面：

- 遍历每个样本的 225 维棋盘，对当前方每个空位模拟落子
- 调用 `check_winner()` 检测是否形成五连
- 共筛出 **226 个**样本 → `debug/sample.json`

### 2. 双模型推理

对 226 个样本分别用 cnn_v9.1 和 cnn_v9.2 推理，得到每个模型的 `policy`（225 维落子概率）和 `value`（[-1,1] 胜率估值），追加到样本中。

### 3. 定量分析

#### v9.1：完全随机（未训练状态）

| 指标 | v9.1 | 参考 |
|---|---|---|
| policy 熵 | 5.413 | 均匀=5.416 |
| 空位概率 CV | ~0.076 | 0=完美均匀 |
| value 均值 | -0.125 | 应接近 1.0 |

policy 偏离均匀仅 0.003 nats，value 对所有局面恒定输出约 -0.12。**v9.1 就是随机初始化的模型。**

#### v9.2：价值头强、策略头弱

| 指标 | v9.2 |
|---|---|
| value 均值 | **0.923** |
| value > 0.9 | **92.9%** |
| value > 0 | 97.3% |

value 几乎完美识别了即将胜利的局面。

| 指标 | MCTS pi | v9.2 policy |
|---|---|---|
| 策略熵 | 1.345 | **5.397** |
| 赢棋位概率和 | 78.4% | **0.72%** |
| argmax 命中赢棋位 | 100% | 19.5% |

v9.2 的 policy 熵与 v9.1（5.413）几乎相同，赢棋位概率不足 1%。**价值头训练充分，策略头几乎没学到。**

---

## 结论

cnn_v9.2 是一只"**知道会赢但不知道该怎么赢**"的模型：

- ✅ value 头：正确判断局面优劣
- ❌ policy 头：输出近乎均匀分布，无法定位致胜落子

这解释了 cnn_v9.2 对战中"value 高但仍输棋"的现象——MCTS 搜索依赖 policy 先验引导，均匀的 policy 导致搜索效率极低。
